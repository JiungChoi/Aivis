# 홈 대시보드 기능 명세

홈 화면은 AIVIS의 메인 허브. 일정·뉴스·시간분석·AI 채팅을 한 화면에서 제공.

---

## 레이아웃

4컬럼 (드래그로 너비 조절 가능):

```
[일정 | 시간분석·작업제안 | 뉴스 | AIVIS 채팅]
```

---

## 1. 오늘의 일정

**현재:** 목업 데이터 (하드코딩)  
**목표:** 로컬 파일 (`~/AIVIS/schedule/`) ↔ Google Calendar 연동

| 기능 | 상태 | 비고 |
|------|------|------|
| 일정 타임라인 표시 | ✅ UI 완료 | 목업 데이터 |
| 현재 시각 기준 활성 항목 강조 | ✅ 완료 | |
| 일정 추가 버튼 | ⬜ 미구현 | |
| 로컬 파일 저장/로드 | ⬜ 미구현 | `~/AIVIS/schedule/` |
| Google Calendar 연동 | ⬜ 미구현 | OAuth2, Phase 2 |

---

## 2. 시간 분석

**현재:** 목업 데이터 (하드코딩)  
**목표:** 일정 태그 데이터 기반 자동 계산, 일별/주별/월별 전환

| 기능 | 상태 | 비고 |
|------|------|------|
| 도넛 차트 UI | ✅ 완료 | |
| 워킹타임·집중블록 통계 | ✅ UI 완료 | 목업 데이터 |
| 실제 일정 데이터 연산 | ⬜ 미구현 | |
| 일별 보기 | ⬜ 미구현 | `analytics/daily-{date}.json` |
| 주별 보기 | ⬜ 미구현 | `analytics/weekly-{week}.json` |
| 월별 보기 | ⬜ 미구현 | `analytics/monthly-{MM}.json` |

### 계산 방식

```
일정 이벤트 태그 → 카테고리 매핑 → 시간 합산 → 차트 렌더링
```

| 태그 | 카테고리 | 색상 |
|------|----------|------|
| 작업, 개발 | 집중 작업 | 파랑 |
| 미팅, 보고 | 미팅 | 보라 |
| 코드리뷰 | 코드리뷰 | 초록 |
| 점심, 휴식 | 휴식 | 회색 |

---

## 3. AI 작업 제안

**현재:** 목업 데이터 (하드코딩)  
**목표:** 사용자 일정·대화 이력 기반 AI 생성, 로컬 파일 캐시

| 기능 | 상태 | 비고 |
|------|------|------|
| 작업 제안 카드 UI | ✅ 완료 | 목업 데이터 |
| AI 생성 로직 | ⬜ 미구현 | LLM 호출 |
| 로컬 캐시 저장 | ⬜ 미구현 | `~/AIVIS/users/{id}/task-suggestions.json` |
| 캐시 TTL (24h) | ⬜ 미구현 | 매일 오전 갱신 |
| 우선순위 필터 | ⬜ 미구현 | |

### 생성 컨텍스트

AI 작업 제안 생성 시 다음 데이터를 컨텍스트로 활용:
- 오늘/이번 주 일정 (`schedule/`)
- 최근 대화 요약 (`conversations/`)
- 미완료 작업 목록 (이전 캐시)
- 사용자 선호도 (`preferences.json`)

## 구현 우선순위 (다음 단계)

```
즉시 구현 가능 (로컬 파일만 필요)
├── 날씨 API 연동 (OpenWeatherMap 무료키)
├── AI 작업제안 실제 생성 + 캐시
└── 워크스페이스 초기화 (WorkspaceManager)

데이터 필요 (일정 연동 후)
├── 시간 분석 실제 계산 (일별/주별/월별)
└── AI 작업제안 일정 컨텍스트 반영

외부 연동 필요
├── 뉴스 RSS 수집 (Background Service)
└── Google Calendar (OAuth2)
```
